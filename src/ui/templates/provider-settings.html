Keys and settings

The app already runs with no keys at all. Each free key below unlocks one more real data source for the site dossier — paste it and it's saved into this app's local configuration, then the server restarts itself. Start with Census (free, sign up and activate the key from the confirmation email) for demographics, then HUD for Fair Market Rents; the rest are optional map and voice extras. Server-side keys stay on this machine; Google Maps and Cesium ion run in the browser and must be provider-restricted. Keys you configured elsewhere are shown but never touched.
