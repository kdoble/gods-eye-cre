# gods-eye-cre: verified data source catalog

Every row below was probed live on 2026-09-22 with curl from this machine unless the
Verified column says otherwise. "Y" means an HTTP 200 and a named field or record was
seen in the body; the how column records what was seen. "UNVERIFIED" means the source
is documented but a live probe did not confirm it this session. Do not promote an
UNVERIFIED row to a Phase 1 dependency.

Test points: Johnson City City Hall, 601 E Main St, Johnson City TN (lat 36.320692, lon
-82.342509); downtown Atlanta (lon -84.3880, lat 33.7490); Doraville GA (lon -84.2170,
lat 33.9010).

License column is about what a public MIT repo may do. Federal sources are US Government
works (public domain). The MIT license covers this repo's code only; every source keeps
its own terms and must be attributed in DATA_SOURCES.md and in the in-app credit lightbox.
